## Prepare access

Prepare [source access, runtime and credentials](/docs/how-to/adf-runtime#prepare-access),
then check this source's vendor prerequisites for permissions, drivers, versions
and authentication setup.

[Read the DB2 vendor prerequisites](https://learn.microsoft.com/en-us/azure/data-factory/connector-db2).

## Configure the connection

The example uses synthetic values. Replace the endpoint and account details with
your source's values. A secret reference such as `${secret:source-password}`
names a secret; it never contains the password itself. `id` is the name a flow
uses in `source`, and `connector` selects the source type.
