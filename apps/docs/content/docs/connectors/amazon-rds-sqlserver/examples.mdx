## Different table watermarks

This connector uses the same `adf-copy` watermark settings as SQL Server.
Follow the [SQL Server worked example](/docs/connectors/sqlserver/examples#example-with-different-table-watermarks)
for per-table overrides and matching store ordering. Its download uses a SQL Server
connection; keep this connector’s own connection and source objects.
