---
title: Connectors
description: The sources Ingestron can read, and how each one is read.
---

A connection's `connector` says what kind of source it is. The packs in your
standard decide how it is read; some sources can be read in more than one
way, depending on how they can be reached
([connectivity](/docs/concepts/connectivity)).

To compare platform combinations first, read
[Choose an ingestion route](/docs/start/choose-a-route).

Choose a category below to find connection settings and supported routes.
To create a project, follow [Create a project from a connection](/docs/how-to/start-from-a-template).
