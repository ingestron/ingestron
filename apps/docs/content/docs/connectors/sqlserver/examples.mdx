## Example with different table watermarks

The standard reads changed rows once an hour using `modified_at`. Customers
inherit that default. Invoices override the watermark with `updated_at` in the
flow and set the store's ordering column to match. The same hourly trigger serves
both tables.

Use the **source column name** for `watermark_column`. A contract's `physicalName`
can rename a selected column, but it does not rewrite the watermark filter.
