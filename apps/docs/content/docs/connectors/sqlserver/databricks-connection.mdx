## What you need

- A Unity Catalog connection to the server, created by an administrator.
  Name it in the connection's `uc_connection`; no credentials go in the
  definitions.
- Change tracking or change data capture enabled on the source tables, as
  Databricks' [SQL Server guide](https://docs.databricks.com/aws/en/ingestion/lakeflow-connect/sql-server-pipeline)
  describes.
