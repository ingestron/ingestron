---
title: Keep a table current from change records
description: Turn files of inserts, updates and deletes into a table of current rows, or of every version.
---

This guide uses the Databricks `streaming-table` method.

Use this when your source drops one row per change: a key, a column that
orders the changes, and often an operation column.

Set the store method's `mode` on the table:

<Example name="change-data" file="flows/crm.yaml" />

- `mode: upsert` keeps the current row per key (SCD type 1).
- `mode: history` keeps every version, with `__START_AT` and `__END_AT`
  columns (SCD type 2).
- `sequence_by` names the column that orders changes. It is required.
- `delete_when` is a SQL condition for rows that delete the key.
- `except_columns` leaves change-only columns out of the table.

The contract must mark the key with `primaryKey: true`; it becomes the
table's key.
