Ingestron generates a job that refreshes the pipelines in order: Lakeflow
Connect ingestion first, then your own pipeline. Outside production the job
is created paused, so development environments do not run on their own; set
`paused: false` to change that.

## Pause everything, or only the copies

When Azure Data Factory copies a source first, its trigger has its own
window (`every` in the standard), but it follows the same switch:
`paused: true` in the platform's `schedule` stops both the job and the Data
Factory trigger.

To stop only the Data Factory copies, for example while the source database
is down for maintenance, set `paused` for the copy method in the platform:

```yaml
settings:
  adf-copy:
    paused: true
```

`ingestron request` lists the state of each schedule, so the platform team
sees the same thing the files say.
