Ingestron turns reviewed YAML definitions into platform files. A project describes
connections, data contracts, flows and transforms. Its standard selects methods
and sets policy; packs implement those methods for the chosen platforms.

Plan shows what would change. Apply writes files; it does not deploy them or move
data. Your platforms run the generated resources after deployment. You can learn
the definition and generation workflow locally without connecting to a source.

## One workflow, different platforms and tools

Definitions and standards are the centre of the project. Packs decide the target
syntax and capabilities; tools let you edit, inspect and generate those files.
Neither your editor nor one platform defines the whole Ingestron workflow.

The current distribution includes Databricks and Azure Data Factory packs, with
specific supported combinations. Check [platform support](/docs/reference/packs)
before choosing a route. Browse [examples](/docs/examples) for working projects
and [tools](/docs/tools) for available ways to use Ingestron.
