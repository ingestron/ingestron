Each download contains synthetic definitions and their checked generated output.
The capabilities listed below are read from the resolved sample project.

To learn the workflow, use [Generate your first project](/docs/start/first-project)
with the `connection-first-files` download, or
[Configure native ADF ingestion](/docs/how-to/adf-native-connectors) with
`connection-first-adf`. Both examples are generated and checked from their
definition files.

## Prepared starters

A starter is a complete project for one common situation. Create your own
project from one, answering a few questions:

```sh
ingestron init my-project --template retail
```

For connection-first creation in the CLI or VS Code, follow
[Create a project from a connection](/docs/how-to/start-from-a-template). Each starter is also a [template](/docs/how-to/share-a-template) like the ones you can write
for your organisation.
