`adf@1` copies tables and files from supported native sources into
landing storage, where the Databricks pack reads them. Use it with the Databricks
pack: `packs: [databricks@1, adf@1]`. The settings below come from the pack
itself.

For a task walkthrough, use [Configure native ADF ingestion](/docs/how-to/adf-native-connectors),
[Configure the project standard](/docs/how-to/configure-a-standard) or
[Name ADF resources](/docs/how-to/name-adf-resources). The reference below
keeps the method and setting anchors used by editor help.

After generation and review, [publish the ADF resources](/docs/how-to/publish-adf)
through the factory's deployment process. Generation itself does not publish.

<PackMethods pack="adf" />
