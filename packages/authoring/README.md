# @ingestron/authoring

Editor features for Ingestron projects, as plain functions over a project's
files: problems and quick fixes, completion and smart defaults, hover
explanations, go to definition, references and rename, and previews of the
generated files. They use the CLI's packs, so an editor and the CLI never
disagree.

The VS Code extension in `apps/vscode` adapts them to VS Code. User
documentation lives on the docs site.
